# Keynote Speaker Photos

Place keynote speaker headshots in this directory.

Use raw GitHub URLs in `keynotes.yaml` so the generated site can load the image directly:

```text
https://raw.githubusercontent.com/SAI-Lab-NYU/VisArch_ISCA26/main/assets/images/keynotes/speaker-name.jpg
```

Supported formats include `.jpg`, `.jpeg`, `.png`, and `.webp`.
